🎓 Student Management REST API

A robust and modular REST API built using Node.js and Express.js to perform complete CRUD (Create, Read, Update, Delete) operations on student records.

This project demonstrates backend development fundamentals, RESTful API design, middleware implementation, modular routing, and efficient data handling using JavaScript arrays.

🚀 Features

✅ View all students
✅ View a student by ID
✅ Add a new student
✅ Update existing student details
✅ Delete student records
✅ Request logging using custom middleware
✅ Modular project structure
✅ RESTful API architecture

🛠️ Tech Stack
🟢 Node.js
⚡ Express.js
📬 Postman (API Testing)
💻 JavaScript
